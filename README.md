# Business Intelligence

## 📌 Overview
This repository features sample dashboards I’ve created to demonstrate my skills in data visualization, dashboard design, and data storytelling.  

## 📊 Professional Projects
I have delivered multiple business intelligence solutions for clients, involving sensitive business data and proprietary designs. Due to confidentiality agreements, these live dashboards cannot be shared publicly.
Below are examples of professional projects I’ve worked on: 

1. **Individual Financial Advisor (IFA) Dashboard (For Hansa Cequity)** 
  - Developed a comprehensive Power BI dashboard for mutual funds clients, enabling regional managers to monitor and analyze key performance indicators and business performance metrics for individual financial advisors.
  - Integrated outputs from multiple machine learning models into the dashboard, providing predictive insights and enhancing decision-making capabilities for regional managers.

2. **Investor Single View Dashboard (For Hansa Cequity)** 
  -	Developed and optimized SQL queries and stored procedures to manage multiple tables and create a unified customer view that was refreshed weekly, enhancing data accuracy and accessibility for mutual fund clients.
  -	Integrated data into marketing dashboards, enhancing efficiency significantly.
